🔐 OAuth Flow Test Suite

Comprehensive testing for Google OAuth2 integration

📋 Test Steps

Step 1: Check OAuth Configuration

Verify that OAuth credentials are configured on the backend.

Step 2: Test OAuth Initiation

Request OAuth authorization URL from the backend.

Step 3: Complete OAuth Flow

Open authorization URL and complete the Google sign-in process.

Step 4: Verify Token Storage

Check that access tokens are properly stored after authorization.

📖 Setup Instructions

  1. Go to Google Cloud Console
  2. Enable "Google My Business API"
  3. Create OAuth 2.0 Client ID (Web application)
  4. Add redirect URI: https://backend.youware.com/api/oauth2/google/callback
  5. Configure credentials using:
    wrangler secret put GOOGLE_CLIENT_ID
    wrangler secret put GOOGLE_CLIENT_SECRET
